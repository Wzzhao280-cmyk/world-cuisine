# 世界美食 · 风味之旅

高质感玻璃拟态（Glassmorphism）风格的世界美食介绍网站。

## 内容

精选六大经典美食：
- 🇮🇹 意大利那不勒斯披萨
- 🇯🇵 日本江户前寿司
- 🇨🇳 中国四川麻婆豆腐
- 🇲🇽 墨西哥瓦哈卡鼹鼠酱
- 🇫🇷 法国普罗旺斯炖菜
- 🇮🇳 印度旁遮普黄油鸡

每道菜包含：具体产地、传统做法、风味品鉴。

## 技术

- 纯 HTML / CSS / JS
- Glassmorphism 玻璃拟态效果
- 响应式设计
- Google Fonts（Noto Sans SC + Playfair Display）

## 部署 GitHub Pages

1. 将本仓库推送到 GitHub
2. 进入仓库 Settings → Pages
3. Source 选择 `Deploy from a branch`
4. Branch 选择 `main`，文件夹选择 `/ (root)`
5. 保存后访问：`https://你的用户名.github.io/仓库名`

## 本地预览

直接用浏览器打开 `index.html` 即可。
